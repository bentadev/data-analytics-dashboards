# 🛒 Dashboard de Compras

**Herramienta:** Looker Studio · **Tipo:** Proyecto académico · **Datos:** simulados
**Materia:** Análisis y exploración de datos (IFTS Nº33)

## 🎯 Objetivo
Explorar **el circuito de compras**: solicitudes, órdenes, contratos, facturación por proveedor y estado de las entregas.

## ❓ Preguntas que responde
- ¿Cuántas solicitudes y órdenes de compra hay, y cuánto se facturó en total?
- ¿Cuál es el rango de precios de los insumos y su promedio?
- ¿En qué productos se invirtió más?
- ¿Cómo se distribuye la facturación entre proveedores?
- ¿En qué estado llegan las mercaderías (conformes, con faltantes, dañadas)?

## 🔍 Qué muestra
- 📌 KPIs de solicitudes, órdenes, contratos vigentes, precio promedio y facturación
- 💲 Rango de precios y búsqueda de insumos por palabra clave
- 📊 Inversión por producto y facturación por proveedor
- 📦 Estado de entrega física de las mercaderías
- 👥 Tabla de empleados del área

## 🗄️ Datos
Base de datos relacional **compras** con datos simulados.
